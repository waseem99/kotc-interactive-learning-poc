# Known Limitations

This POC intentionally does not include:

- Real authentication or account creation
- Real user, progress, certificate, or analytics data
- NestJS APIs
- Strapi CMS integration
- PostgreSQL persistence
- Amazon Cognito configuration
- AWS infrastructure
- Real media, captions, transcripts, or downloadable resources
- Real certificate generation or verification
- Payment or monetization features
- Final curriculum
- Final Indigenous imagery, language, symbolism, stories, or brand treatment
- Formal third-party accessibility certification

Browser `localStorage` is used only to simulate progress and preferences on the current device. All dashboard values are illustrative.
